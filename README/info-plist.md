# Info.plist

Info.plistは、iOSおよびmacOSにおいて、アプリやバンドルに関する重要なメタデータや設定情報を格納するために使用される特別なファイルです。このファイルは、システムがアプリの動作を理解し、適切に機能させるために不可欠な役割を果たします。

以下にInfo.plistの概要と詳細をまとめます。

## Info.plistとは**
- Info.plistは「information property list file（情報プロパティリストファイル）」の略称です。
- これは、システムが実行時にアクセスできる任意のデータを構造化する方法であるプロパティリストの一種であり、**バンドルの設定データを含む特殊なプロパティリスト**です。
- すべてのアプリとプラグインは、システムが簡単に設定データにアクセスできる場所としてInfo.plistファイルを使用します。
- Info.plist を開発/リリース/テスト に分けて作成することで、実行環境を切り分けることが可能

## 目的と重要性**
- Info.plistに格納されたメタデータは、ユーザーエクスペリエンスを向上させるためにiOSおよびmacOSによって利用されます。
- このメタデータは、ユーザーへの表示、システムによるアプリ識別、サポートするドキュメントタイプの特定、アプリの起動を容易にするためのシステムフレームワークによる内部利用など、さまざまな方法で使用されます。
- ファイル内のキーと値は、バンドルに適用したい多様な動作や設定オプションを記述します。
- macOSおよびiOSはInfo.plistファイルを使用して、バンドルに表示するアイコン、アプリがサポートするドキュメントの種類、およびバンドル自体以外に影響を与える他の多くの動作を決定します。

## 編集と構成**
- Xcodeプロジェクトテンプレートは、通常、初期のキーセットと適切なデフォルト値を持つ情報プロパティリストファイルを指定します。
- プロジェクトの要件に応じて、ファイルを編集してキーと値を追加または変更することができます。

## Info.plistに含まれる主要なキーの種類**

- CFBundleIdentifier: アプリの一意識別子
- CFBundleDisplayName: ホーム画面に表示されるアプリ名
- CFBundleShortVersionString: ユーザーに表示されるバージョン
- CFBundleVersion: 内部ビルド番号
- CFBundleURLTypes: URL Scheme設定
- FirebaseAppDelegateProxyEnabled: Firebaseの設定
- LineSDKConfig: LINE SDK の設定
